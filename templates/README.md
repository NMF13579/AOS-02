# AOS-02 Templates

These YAML files are drafting aids for the documentation-first workflow. Copy a template into a task-specific folder, give it a stable ID, and fill only observed or explicitly decided values.

**Important:** a filled template is not a real approval, execution grant, or evidence claim. A real decision requires a separately identified human acceptance under the canonical governance contracts.

Available templates:

- `idea-record.yaml`
- `risk-profile.yaml`
- `scope-and-change.yaml`
- `task-brief.yaml`
- `evidence-report.yaml`
- `human-decision-record.yaml`
