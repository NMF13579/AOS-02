# Manual Control Workflow v0 — Illustrative Example

This is a fictional, documentation-only example. It demonstrates the chain:

```text
idea → risk → scope → task brief → human execution decision → evidence → human result decision
```

It does **not** authorize real work. The fictional task is to add a short glossary note to an imaginary documentation set. Its value is traceability: every record points to the one before it, and the final result states what was not checked.
